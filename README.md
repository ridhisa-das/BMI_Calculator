# BMI_Calculator

>>Project Overview

This project is a beginner-level Python BMI Calculator. It takes the user's weight and height as input, calculates the Body Mass Index (BMI), and displays the corresponding BMI category.

>>Technologies Used

- Python
- Google Colab

>>Features

- Takes weight in kilograms
- Takes height in metres
- Calculates BMI using the BMI formula
- Displays BMI rounded to 2 decimal places
- Classifies the BMI result
- Validates user input
- Rejects non-numeric input
- Rejects zero and negative values
- Allows repeated calculations

>>BMI Formula

BMI = Weight / (Height²)

Example

Input:

Weight: 60 kg
Height: 1.65 m

Output:

BMI: 22.04
Category: Normal

>>How to Run

1. Download "BMI_Calculator.py".
2. Open it in a Python environment such as Google Colab or Pydroid 3.
3. Run the program.
4. Enter your weight in kilograms.
5. Enter your height in metres.
6. The BMI and category will be displayed.
